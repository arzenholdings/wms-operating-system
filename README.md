# WMS Operating System

This repository is the source-of-truth operating framework for Workplace Management Solutions (WMS).

It preserves the customer journey framework exported from Lucid and the spreadsheet framework files, then maps them into a lightweight operating system for repeatable delivery across:

- WMS clients
- Arzen Commerce
- Kinetic Moto
- Driver Network
- Future customer implementations

## Repository Structure

- `docs/` - Framework summaries and operating-system documentation.
- `source-exports/` - Original Lucid PDF exports, spreadsheet exports, and backup artifacts.
- `linear/` - Linear implementation plans, issue templates, milestones, and project notes.
- `gohighlevel/` - GoHighLevel pipeline, tag, workflow, and automation mapping.
- `sops/` - Standard operating procedures for onboarding, delivery, retention, and reactivation.

## Operating Principles

- Do not reinvent the framework.
- Keep architecture lightweight and operational.
- Focus on repeatable delivery systems.
- Use GoHighLevel as the CRM and automation runtime.
- Use Linear for implementation tracking and operational planning.
- Use SOPs to make delivery repeatable across clients and brands.
- Avoid unnecessary agency-style structures or overbuilt process layers.

## Source Framework

The source framework centers on the lifecycle:

`Target -> Attract -> Capture -> Engage -> Offer -> Close -> Delivery -> Impress -> Multiply`

Internal operations, reporting, technology, and finance workflows are handled through the `Internal` layer.
