# WMS Architecture Topology Import Instructions

Use `WMS-Architecture-Topology.mmd` as the Lucid-ready Mermaid source.

## Import Into Lucid

1. Open Lucid.
2. Create or open the WMS operating architecture board.
3. Choose the Mermaid import option.
4. Open `docs/WMS-Architecture-Topology.mmd`.
5. Copy the full Mermaid source.
6. Paste it into Lucid's Mermaid import panel.
7. Import the diagram.
8. Arrange spacing if needed, but keep the topology structure intact.

## Recommended Lucid Layout

- Keep `Top Layer` at the top.
- Keep `Strategic Framework` and `Version-Controlled Operating System` in the middle.
- Keep `Execution Systems` and `Shared System Tools` below the operating system layer.
- Keep `Business Lanes` across the bottom.

## Guardrails

- Do not add new companies.
- Do not split the model into unnecessary departments.
- Do not turn the diagram into a marketing-agency org chart.
- Keep OpenClaw as an escalation path only.
- Keep GoHighLevel as the lifecycle execution layer.
- Keep Linear as implementation tracking.
- Keep GitHub as the version-controlled operating system.
- Keep Lucid as the strategic framework source.
